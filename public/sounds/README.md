# Звуки для игры

## Требуемые файлы

### footstep.mp3
Звук шагов по полу (паркет/бетон).

**Рекомендации:**
- Формат: MP3 или WAV
- Длительность: 0.3-0.5 секунды
- Частота дискретизации: 44100 Hz
- Битрейт: 128-192 kbps

**Где найти:**
- [Freesound.org](https://freesound.org) - поиск "footstep wood" или "footstep concrete"
- [OpenGameArt.org](https://opengameart.org) - звуки шагов
- [Zapsplat](https://www.zapsplat.com) - бесплатные звуковые эффекты

**Примеры поисковых запросов:**
- "footstep wood floor"
- "footstep concrete"
- "walking sound effect"

После загрузки файла переименуйте его в `footstep.mp3` и поместите в эту папку.
